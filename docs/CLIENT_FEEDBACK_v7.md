## 実装しなかった/変えた判断の理由

### ⑲ 解約の店舗限定について（重要）
以下の理由から、**アプリ内で解約を完結できる状態を維持**することを強く推奨します。

1. **法規制**: 特定商取引法の通信販売規制（2022年改正）で、サブスクリプションの解約手続きを不当に困難にすることは行政処分の対象になり得ます。オンラインで加入できるのにオフラインでしか解約できない設計は「解約妨害」と評価されるリスクが高いです。
2. **ストア規約**: 将来ネイティブアプリ化してアプリ内課金にする場合、Apple/Googleの規約で解約はストア経由となり、店舗限定にはそもそもできません。
3. **UX/ブランド**: 解約導線を隠すと解約率は下がらず、不信感とレビュー低下につながるのが一般的です。
4. **代替案（実装済み）**: 解約ボタン→「プラン変更（月1回に落とす）」「スタッフに相談」を提示→それでも進む場合は解約、という**引き止めは丁寧に・手続きは妨げない**2段階を実装しました。休眠→再開のハードルを下げる方が LTV に効きます。

### ⑪ アプリアイコンの表情変化
Webアプリ（LIFF含む）ではOSの制約上実装できません。ネイティブ化の際の実装メモ：
- iOS: `setAlternateIconName`（事前に用意したアイコンセットへの切替。バックグラウンドでの自動切替は不可のため、アプリ起動時に「前回起動からの経過日数」で切替）
- Android: `activity-alias` の有効/無効切替で同等の表現が可能
- 併せて通知（プッシュ）側で表情絵文字を変える運用が現実的です

### ⑮ 睡眠ランク制度
本診断ランク（A〜D）・スーピーくんのレベル/称号と3つ目の「ランク」を並走させると、ユーザーが把握すべき指標が増えすぎます。⑭の実店舗特典の設計が決まったタイミングで、「レベル→特典」の形で統合するのが最も分かりやすいと考えます。
