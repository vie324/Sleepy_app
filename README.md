# 睡眠整体サロン SLEEPY 公式アプリ 🐑🌙

**─ 睡眠から、人生を変える。─**

株式会社SLEEPYのWebアプリケーション。**顧客向けアプリ**と**スタッフ向け管理コンソール**の
2画面構成で、AI診断 × 体験 × 施術 × ホームケア × アプリ × EC のプラットフォーム体験を
サーバー不要のスタンドアロンHTMLとして実装しています。

| ファイル | 対象 | 内容 |
| --- | --- | --- |
| `index.html` | お客さま | カウンセリング表・スーピーくん育成・睡眠記録・診断・姿勢レポート・EC・回数券・次回予約・来店ガイド |
| `admin.html` | スタッフ・管理者 | ダッシュボード・顧客カルテ・要フォロー抽出・売上・データ取り込み（デモPIN: **1234**） |

![SLEEPY ロゴ](assets/logo.jpg)

## 管理コンソール（admin.html）

- **ダッシュボード** — 顧客数／本日・直近30日の来店／物販売上／サブスクMRR、**要フォロー顧客の自動抽出**（来店21日以上空き・記録7日停止・回数券切れ/残1・期限間近・低スコア）、本日の来店、最近の改善レポート
- **カウンセリング受信箱** — お客さまがLINE（リッチメニュー想定）から送信したカウンセリング表がダッシュボードに届く。**AI分析（自律神経の推定・主課題ランキング・カウンセリングの切り口・施術フォーカス・提案プラン/商品）はスタッフ専用表示**で、ワンタップで顧客カルテへ保存（未登録のお客さまは新規カルテを自動作成）
- **顧客一覧** — 検索（名前/かな/会員番号）、並び替え（来店順/スコア低い順/名前順）、7日スコアのスパークライン、フォローバッジ
- **顧客カルテ** — プロフィール＋スタッフメモ（お客さまには非表示）／**次回予約の設定（保存と同時にお客さまアプリのホーム・会員証へ表示）**／**最新カウンセリング表＋スタッフ専用AI分析**／睡眠推移チャート・行動集計／**姿勢分析の撮影（カメラ/写真/デモ→スコア化→お客さまアプリへ自動配信）**と履歴／来店履歴と改善レポート閲覧／回数券・サブスク・購入履歴
- **売上** — 直近30日集計・売れすじランキング・注文一覧・サブスクMRR
- **データ連携（デモ）** — お客さまがアプリの「設定→データを書き出す」で保存したJSONを取り込むとカルテが最新化。同一端末ならワンタップ取り込みも可。**実運用ではこの部分を認証付きバックエンド（DB/API）での自動同期に置き換えます**（デモ顧客8名を同梱）

## v7: 役員フィードバック対応（状態→原因→行動の一本化）

「開いたら迷わない」を軸に顧客アプリを再構成しました。詳細な対応表と実装判断は **[docs/CLIENT_FEEDBACK_v7.md](docs/CLIENT_FEEDBACK_v7.md)** を参照。

- **ホーム再設計** — 最上位に「きょうの状態」（睡眠スコア＋前日比＋原因）と「きょうやること」（記録・処方ストレッチ・入浴/ホームケア・来店提案を自動生成）。お知らせバナーは1枠のみ・閉じられる
- **じたく⇄店内モード** — 利用シーンで画面を切替。店内＝来店ガイド・スタッフに見せるデータ・本診断・施術前後比較・商品体験。チェックインで自動切替
- **週間AIフィードバック** — 直近7日vs前7日（スコア/時間/中途覚醒/就寝ばらつき/入浴）を文章で解説＋今週のフォーカス提案
- **本診断の強化** — 全30問の進捗・残り時間表示、**途中保存＆再開**、結果の自動保存明示、結果→施術・アイテム・自宅ケア・おすすめ周波数の提案チェーン
- **つづけるカレンダー** — 記録/ストレッチ/入浴/来店/買い物の5種スタンプ・連続日数・達成率
- **SHOP悩み別化・サブスク提案型** — 「ぐっすり眠りたい」等の悩み起点導線、診断データからの推奨プラン提示（理由つき）
- **購入後フォロー** — 購入3日後に定着チェック→定期便/使い方へ接続
- **アカウント引き継ぎ** — 店舗タブレット⇄個人スマホのデータ引き継ぎ（書き出し→読み込み、実運用はLINEログインで自動化）
- **その他** — カウンセリング表のセクション進捗、そだてる「つぎのごほうび」、文字拡大設定、解約前の引き止め2段階（アプリ内解約は維持）

## LINE→来店→登録の導線（v6）

「LINE追加 → リッチメニューからカウンセリング表 → 管理側でAI分析 → 姿勢分析 → 施術 → 再分析 → プラン・回数券購入時にアカウント登録 → 予約・残数の確認」の一連をデモ実装しています。

| # | 流れ | 実装 |
| --- | --- | --- |
| 1 | LINEリッチメニュー→カウンセリング表 | ホームのCTA・来店ガイドStep1から入力（3分・10のお悩み+生活習慣+自由記入） |
| 2 | 睡眠・自律神経の簡易分析 | 送信直後にお客さまへは**やさしいタイプ判定のみ**表示（詳細は来店時に） |
| 3 | 管理側ダッシュボードに表示 | カウンセリング受信箱→**スタッフ専用AI分析**（課題ランキング・切り口・提案）→カルテ保存 |
| 4 | AI姿勢分析→施術→再分析 | 管理側で撮影しBefore/After配信（既存機能） |
| 5 | プラン・回数券購入者にアカウント登録 | 未登録ゲストは加入/回数券購入時に**登録モーダル**（実運用はLINE ID連携で入力ゼロ） |
| 6 | 次回予約・残数の確認 | 管理側カルテで予約設定→お客さまのホーム・会員証に表示。回数券残数は会員証に常設 |

## 使い方

1. `index.html` をブラウザ（Chrome推奨）で開く
2. オンボーディングで「**デモデータ入りではじめる**」→ 全機能をすぐ体験できます
3. データは端末の `localStorage` のみに保存（設定からリセット可）

```bash
# ローカルサーバーで開く場合
python3 -m http.server 8000   # → http://localhost:8000
```

## スーピーくんの表示メディア（3段階の自動アップグレード）

ホーム・そだてるのキャラ表示は、置いてあるアセットに応じて自動で最良のものを選びます。

| 優先 | アセット | 内容 |
| --- | --- | --- |
| ① | `assets/soupy.mp4`（**同梱済み**・公式リール映像） / `assets/soupy.webm` | **リール級のアニメーション動画**をループ再生（自動再生・ミュート・ループ）。差し替えは同名ファイルを置くだけ |
| ② | `assets/soupy.glb`（同梱済み） | リアルタイム3D。three.jsでプログラム生成した3D版スーピーくんに、**まばたき・ぽよんぽよん跳ね（スクワッシュ&ストレッチ）・耳の二次揺れ・ぎゅっと抱きしめ・月のロッキング**のidleアニメ入り。ドラッグで回転できます |
| ③ | （なし / file:// / 読込失敗） | SVG版スーピーくん＋擬似3Dチルト。どの環境でも必ず動くフォールバック |

- ①②は http(s) 配信時に有効（Vercel / `python3 -m http.server`）
- 差し替えは**同名ファイルを置くだけ**。アプリ側の変更は不要です
- リール級の品質を目指す場合：既存のリール動画素材（またはその制作元データ）を
  `soupy.webm`（背景透過ならなお良い）で書き出して配置するのが最短ルートです

**制作を発注する場合の仕様メモ**
- 形式: glTF 2.0 (.glb) / 5,000〜20,000ポリゴン / PBRテクスチャ1〜2枚(1024px)
- リグ: 頭・耳L/R・まぶた・毛布のボーン＋まばたき/口のブレンドシェイプ
- アニメーション: `idle`(呼吸+ゆれ) を既定再生。他に `happy` `sleep` `bounce` があると拡張しやすい
- 参考素材: ブランドビジュアル（三日月×毛布の羊）＋ `assets/logo.jpg`
- Blender(無償)で制作可。画像→3D生成AI（Meshy/Tripo等）で下地を作りリトポ・リグ調整する方法も低コスト

## デザインシステム（v4）

- **絵文字は不使用** — 約50種の自社ラインアイコン（24px・1.7pxストローク）で統一
- ブランドシートと同じ **金のENキッカー＋日本語見出し** の編集的レイアウト（例: DAILY MISSIONS｜きょうのミッション）
- 書体: Noto Sans JP（UI）× Shippori Mincho（ブランド表示）。スーピーくんのふきだしのみ丸文字（Zen Maru Gothic）でキャラの声を演出
- 角丸を全体に絞り（カード13px/ボタン10px/チップ8px）、ヘアライン罫線で上質に
- チャート配色はネイビー面でコントラスト・CVD検証済み

## 技術構成

- 単一HTML（React 18 UMD + Babel Standalone + Tailwind）— ランタイムは `vendor/` に同梱で**オフライン動作**
- フォント: Zen Maru Gothic / Shippori Mincho（ブランドセリフ）※CDN不達時はシステムフォント
- 骨格検出: `@mediapipe/pose`（分析時のみCDN読込。デモ分析はオフライン可）
- 3D: `@google/model-viewer`（vendor同梱・GLB設置時のみ起動）
- チャート配色はダークネイビー面(#222e4c)でコントラスト・CVD検証済み
