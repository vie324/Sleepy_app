# 睡眠整体サロン SLEEPY 公式アプリ 🐑🌙

睡眠をテーマにした整体院「SLEEPY」の**顧客向けWebアプリケーション**です。
ロゴのマスコット「**スーピーくん**」と一緒に、ねむれるからだを育てていきます。

`index.html` をブラウザで開くだけで動作します（サーバー不要・スタンドアロン）。

![SLEEPY ロゴ](assets/logo.jpg)

## 機能一覧

| 機能 | 内容 |
| --- | --- |
| 🐑 スーピーくん育成 | ロゴに忠実なSVGで再現。ふわふわ浮く・呼吸する・まばたき・Zzz・なでるとよろこぶ等のアニメーション。睡眠記録や来店でXPがたまりレベルアップ。きせかえ（ナイトキャップ/まくら/毛布/ランプ 等）が解放されます |
| 🌙 睡眠記録・睡眠スコア | 就寝・起床時刻／ねむりの質／中途覚醒／朝の気分／行動チェックから**睡眠スコア(0-100)** を算出。7日間の推移グラフ・睡眠時間グラフ付き |
| ⚖️ 自律神経バランス | 毎日の行動から交感神経⇄副交感神経のバランスを推定し、ダイバージングメーターで見える化。状態に応じたアドバイスを表示 |
| 📖 教育コンテンツ「まなぶ」 | 「日々の行動がすべて自律神経・睡眠につながる」ことを学べる記事8本＋おさらいクイズ。行動チェックの各項目にも ⓘ 解説付き |
| 🤸 ストレッチ指導 | 8種のストレッチをガイド付きタイマーで実行。各ストレッチに「からだへの効果」「自律神経へのはたらき」を明記。完了でXP |
| 🛍️ ECサイト（ショップ） | 快眠グッズ・回数券の購入（デモ決済）。**睡眠記録×姿勢分析の結果から「あなたへのおすすめ」を理由付きで自動提案** |
| 🎫 回数券・会員証 | 回数券の残回数・有効期限・利用履歴を表示。会員証カード＋来店チェックイン（チェックインで回数券を1回消化・+50XP） |
| 📸 姿勢分析 | MediaPipe Pose による骨格検出。正面（頭・肩・骨盤の傾き、重心）／側面（頭部前方角=スマホ首、体幹の前後傾、軸ライン）をスコア化し、**施術前後のBefore/After比較**で変化を体感。結果はすべて睡眠・自律神経の解説につながります。カメラ／写真アップロード／デモの3入力に対応 |
| 🏥 来店ガイド | ご来店〜退店までの理想の導線をステップ形式でガイド：チェックイン → カウンセリング（直近の睡眠サマリー表示）→ 姿勢チェック(前) → 施術（呼吸ガイド付き）→ 姿勢チェック(後)＋比較 → ストレッチ処方 → 本日のご提案 → 次回案内・完了 |

## 使い方

1. `index.html` をブラウザ（Chrome推奨）で開く
2. 初回はオンボーディングで名前とお悩みを入力
   - 「**デモデータ入りではじめる**」をONにすると、2週間分の睡眠記録・回数券・姿勢分析サンプルが入り、全機能をすぐ確認できます
3. データは端末の `localStorage` にのみ保存されます（設定からリセット可能）

ローカルサーバーで開く場合:

```bash
cd Sleepy_app
python3 -m http.server 8000
# → http://localhost:8000
```

### 姿勢分析カメラについて

- カメラは **HTTPS または localhost**（Chromeでは `file://` も可）で動作します
- カメラが使えない環境では「写真をえらぶ」「デモでためす」をご利用ください
- 骨格検出モデル（MediaPipe Pose）は初回のみCDNから読み込むため、ネット接続が必要です

## 技術構成

- 単一HTMLファイル（React 18 UMD + Babel Standalone + Tailwind CDN）— 参考実装の姿勢分析ツールと同じ構成
- フォント: Zen Maru Gothic / Noto Sans JP
- 骨格検出: `@mediapipe/pose`（分析開始時に動的読み込み）
- グラフ配色はダークネイビー面(#222e4c)に対して検証済み（コントラスト・色覚多様性チェックPASS）
  - スコア推移: `#bd861a` ／ 睡眠時間: `#6d82ec` ／ 交感 `#df5346` ⇄ 副交感 `#25a08c`

## カスタマイズポイント

すべて `index.html` 内のマスターデータを編集するだけで反映されます。

| 変更したい内容 | 場所（セクションコメント） |
| --- | --- |
| 行動チェック項目・自律神経への影響度 | `SECTION 1` の `HABITS` |
| 教育記事・クイズ | `SECTION 1` の `ARTICLES` |
| ストレッチメニュー | `SECTION 1` の `STRETCHES` |
| 商品・価格・回数券 | `SECTION 1` の `PRODUCTS` |
| おすすめ提案のルール | `SECTION 3` の `RECIPES` |
| レベル・きせかえ解放 | `SECTION 2` の `STAGES` / `ACCESSORIES` |
| 来店ガイドのステップ | `SECTION 16` の `VisitFlowScreen` |

## メモ

- 「理想の来店〜退店の導線」の添付画像はセッションに届いていなかったため、来店ガイドはご要望の機能一式（姿勢の前後比較・ストレッチ処方・物販提案・回数券消化）を通る標準的な導線で実装しています。画像の流れと違う箇所があれば `VisitFlowScreen` のステップ配列の編集で調整できます
- 決済はデモです。実運用では決済・予約・LINE連携などのバックエンドAPIに接続してください
